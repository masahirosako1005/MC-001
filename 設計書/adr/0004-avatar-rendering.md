# ADR 0004: アバターの描画方式

- 状態: 採用
- 日付: 2026-11-09(同日改訂: ちびキャラ風デザイン・体のタイプ・目の色・男女別サンプルパーツ・管理者の自由選択)

## 決定

アイテムは「部位 × 形(固定テンプレート) × 色(#RRGGBB)」のパラメータで表し、サーバーで SVG を組み立てる(`wardrobe/avatar.py`)。運営が任意の SVG やファイルをアップロードする方式は採らない。

### デザイン(改訂)
- 参考画像の雰囲気に合わせた**ちびキャラ風**: 頭が全身の約 1/3、グラデーションとハイライトの入った大きな瞳、前髪・後ろ髪・横髪を重ねた髪型、ほお紅
- 参考画像の特定キャラクターの複製ではなく、オリジナルの形テンプレートとして作成
- 体のタイプ **「女の子」「男の子」**: 目の形・まつ毛・眉・口が異なる。体の骨格は共通なので、どのパーツもどちらの体に着せても破綻しない
- **目の色** 6 色、肌の色 8 色(現実の幅広い肌色 + ファンタジー色)
- 形テンプレート: 髪 12 / トップス 12 / ボトムス 9 / くつ 6 / こもの 10

### 体のタイプとパーツ
- `Item.body_type` = 女の子用 / 男の子用 / 共通、`AvatarConfig.body_type` / `eye_color` を追加(DB の CHECK 制約あり)
- 体のタイプは**だれでも自由に選べる**(登録者の性別は聞かない・保存しない)。着せ替え画面には選んだタイプに合うパーツが表示される
- 一般利用者: 持っているパーツのうち、体のタイプに合うものだけ着られる(サーバー側で検証)
- **管理者(運営スタッフ): 持っていないパーツも、別のタイプのパーツも自由に選べる**(付与はしない)。「ほかのタイプのパーツも表示する」で全パーツを表示。全パーツ一覧 `/wardrobe/catalog/`
- サンプルパーツ: **女の子用 50 種類・男の子用 50 種類**(`wardrobe/sample_items.py`、`seed_mikke` で投入)。各タイプに初期セット(髪・トップス・ボトムス・くつ)あり。探索で出ていないパーツはデモ用シンボルのドロップに自動で割り当てる
- 既存のアバターは、マイグレーションで今の髪型から体のタイプを推定した(あとで自由に変更可)

### 改訂 2: 目の大きさ・顔パーツ・背景・エフェクト
- 目を自然な大きさに縮小(以前の約 65% の面積。両目の幅の合計が顔幅の半分以下 = テストで確認)
- **顔パーツ 12 種類**(目・眉・口・ほお紅のセット): ふつう / にっこり / うれしい(^^) / ウインク / たれ目 / つり目 / まんまる / ねむそう / ねこぐち / クール / キラキラ瞳 / てれ。色はほお紅の差し色
- **背景 20 種類**(`wardrobe/scenes.py`): クリーム・青空・夕焼け・星空・桜並木・紅葉・雪景色・海辺・お城・川べりの街・神社・お祭り・温泉・カフェ・ステージ・夜の街・森・虹・水玉・ハート柄
- **エフェクト 10 種類(アニメーション)**: キラキラ・ふわふわハート・くるくるスター・花びらの舞・音符・シャボン玉・粉雪・紙ふぶき・オーラ・ほたる
- アニメーションは **GIF ではなく SVG 内の CSS アニメーション**にした
  - GIF は 256 色・拡大でぼやける・ファイルが大きい。SVG なら色数制限がなく、どの大きさでもくっきり、数 KB で済む
  - サーバーで画像を生成しない(この環境ではネイティブの画像ライブラリが使えない)
  - `prefers-reduced-motion`(OS の「視差効果を減らす」)が有効なら動きを止める(WCAG 2.2 2.3.3)
  - `<img>` で表示した SVG でもアニメーションは動く(ブラウザで確認)。SVG 内のスクリプトは使わない
- 顔・背景・エフェクトは「共通」パーツ(12 + 20 + 10 = 42 種類)。初期アイテムは「ふつうの顔」「クリーム背景」

## 理由

- **安全性**: 任意 SVG はスクリプト注入(XSS)の温床。色は DB の CHECK 制約と描画時の正規表現で二重に検証し、文字列は全てエスケープ
- SVG レスポンスには `Content-Security-Policy: sandbox` を付け、単体で開かれても実行不能
- 管理画面から色と形を選ぶだけで新アイテムを追加できる(運用コストが低い)
- 多様性: 性別を入力させず、体のタイプは見た目の好みとして自由に選べるようにした

## トレードオフ

- 表現の自由度は形テンプレートの数に依存 → `STYLES` に形を追加して拡張する
- 参考画像のような柄(花柄・チェックの細部)は簡略化している。より細かい柄が必要なら、テンプレートに SVG の pattern を追加する
