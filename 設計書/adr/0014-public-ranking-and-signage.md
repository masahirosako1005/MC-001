# ADR 0014: 「こんな人も獲得しているよ」・ログイン画面のランキング・まちのサイネージ

- 状態: 採用
- 日付: 2026-11-10

## 背景
- みっけした直後に、同じコーデを手に入れたほかの人が目に入るようにしたい (レア度の横に 3 人くらい)
- ログイン画面で「いま、まちで手に入るコーデ」とコーデコンテストのランキング上位を、右から左へ流して見せたい
- サイト運営者が、ランキング 1 位のコーデと宣伝の文をデジタルサイネージに出し、まちの宣伝に使いたい
- ログイン前の画面やまちのサイネージは**だれでも見られる**ので、利用者の名前の扱いに気をつける必要がある

## 決定

### 結果画面の「こんな人も獲得しているよ」
- 受け取り API (`POST /explore/api/collect`) の結果に `item_finders` を付ける: **同じアイテム**を**直近 7 日**に手に入れた人を新しい順に 3 人
- 出す人・出す情報・開き方は ADR 0011 の「こんな人が獲得しているよ」と同じ (「みっけ仲間に表示する」が ON の利用者だけ、ニックネーム・今のコーデ・おおまかな時間、見る人に結び付いたランダムな ID でしか開けない)
- 時間の表示は「さっき / ◯分前 / ◯時間前 / ◯日前」(正確な時刻は出さない)
- 絵の右 (レア度の横) に縦に並べ、押すとその人のコーデを開く。下の「こんな人が獲得しているよ」(同じスポットの直近 30 分) はそのまま

### 公開の画面に出すランキング
- 対象のコンテスト: 開催中のもの (新しい順)。なければ直近に終わったもの (`contest.services.featured_contest`)
- 上位は BOT を除いた高評価順 (ランキング画面と同じ)。**名前 (コンテストの表示名) を出すのは「みっけ仲間に表示する」を ON にしている人だけ**。OFF の人は「2位のコーデ」のようにアバターだけを出す。順位は変えない
- アバターの絵は順位の番号でしか取れない (`/contest/top/<順位>.svg`、ログイン不要)。エントリーの ID は公開の画面に出さない

### ログイン画面の流れる表示
- 「いま、まちで手に入るコーデ」(ADR なし、core/showcase.py) とランキング上位 3 位を 1 本の帯にして、CSS アニメーションで右から左へ流す (同じ内容を 4 つ並べて切れ目なく回す。2 つ目以降は読み上げない)
- 動く表示は止められるように「一時停止」ボタンを付ける (WCAG 2.2.2)。マウスを乗せる・フォーカスしても止まる。動きを減らす設定の人には流さず、横スクロールで見せる

### まちのサイネージ (signage アプリ)
- 運営コンソールの「まちの宣伝 > サイネージ」で作る: 名前 (設置場所)・見出し・宣伝の文 (200 文字まで)・QR コード (リンク先は空欄ならサイトのトップ)・更新間隔 (15〜3600 秒)・表示する / 止める。編集画面に実際の見た目のプレビューを出す
- 表示は `/signage/<表示キー>/`。**ログイン不要**で、サイネージの端末のブラウザで開いて全画面にする
  - 表示キーはランダム (192bit) で推測できない。漏れたら「URL を作り直す」で古い URL を使えなくする。止めたサイネージ・違うキーは 404
  - 内容: ランキング 1 位のアバター (名前は上の規則)・コンテスト名・高評価数・見出し・宣伝の文・QR コード (segno で SVG)。1 位がいなければ「ランキング集計中」
  - 更新は `<meta http-equiv="refresh">` (スクリプトを使わない)。`noindex`。宣伝の文は自動エスケープし、改行だけ `<br>` にする
  - 16:9 の画面をコンテナクエリの単位 (cqw) で組み、端末の画面いっぱいでも、運営コンソールの小さなプレビューでも同じ見た目にする
- 作成・更新・URL の作り直し・削除は監査ログに残す
- 管理者 (店舗) のログイン中でも、公開の画像・サイネージは管理者の画面に戻さない (`RoleAreaMiddleware` の公開の一覧)

### 静的ファイルの名前にハッシュを付ける
- nginx は静的ファイルを 7 日キャッシュさせるため、CSS・JS を更新しても前のものが使われ続けた (ログイン画面の流れる表示が崩れて見えた)
- DEBUG でないときは `ManifestStaticFilesStorage` で名前に内容のハッシュを付ける (`mikke.9d8fef139326.css`)。中身が変わると URL も変わる。collectstatic は起動スクリプトが行う。テストではハッシュなしの保存方法にする

## 結果
- みっけの直後に、同じコーデを持つ人のコーデへすぐ移れる
- ログイン前の人にも、季節のコーデと上位のコーデが目に入る
- サイネージの端末はブラウザで URL を開くだけで使え、ランキングが変わると自動で切り替わる
- 公開の画面に名前が出るのは、本人が表示を ON にしている場合だけ
- サイネージの QR のリンク先は、公開している URL を入れておく必要がある (空欄だと、開いた端末から見たサイトの URL になる)
