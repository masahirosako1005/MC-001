# ADR 0008: UI テーマ(デザイン案)の切り替え

- 状態: 採用
- 日付: 2026-11-09

## 背景

使いやすい UI を比較検討するため、ログイン前・ログイン後・その他のページを含む複数のデザイン案を用意し、管理画面から切り替えたい。ログイン前ページには仮想の写真画像を使う。参考画像(スマホゲームのホーム画面)のように、1 画面で主要機能にたどり着ける UI も試す。

## 決定

### 4 つの案(`core/themes.py`)

| 案 | ログイン前 | ログイン後ホーム | 全ページ共通の見た目 |
|---|---|---|---|
| A. スタンダード | 説明カード + 写真ギャラリー | カード縦並び | 現行デザイン |
| B. ゲームホーム(1画面完結) | タイトル画面風(写真背景・大きな「はじめる」) | **1 画面完結**: 上部ステータス(旅ランク・アイテム数・スポット数・クーポン数・メニュー)、左にイベント、中央に大きなアバターとセリフ、右にアイコンボタン(バッジ付き)、下に大きなボタン。スクロールなし | ポップな配色・立体ボタン・白縁カード |
| C. トラベルマガジン | 全面写真のヒーロー + 写真の特集グリッド | 「旅ノート」風 | 明朝体の見出し・余白広め・直線的 |
| D. 和モダン | A と同じ構成 | A と同じ構成 | 藍 × 朱、和紙色に青海波の模様 |

- 参考画像は既存の商用ゲームのため、**画面のまとめ方の考え方だけを参考にし、デザイン・絵・名称はすべて独自**に作った
- 1 画面ホームのアバターは「背景だけ」(`/wardrobe/me.svg?layer=bg`、画面いっぱいに敷く)と「アバターだけ」(`?layer=avatar`)を重ねて表示。セリフは時間帯に合わせて変わる
- 旅ランクはみっけ回数から E / D / C / B / A / S

### 仮想写真(`static/img/photos/*.svg`、`scripts/make_photos.py` で生成)
- Claude が作った**写真風の CG イラスト**(夕暮れの川べり・桜とお城・提灯の路地・湯けむりの温泉街・港のれんが倉庫)。グラデーション・被写界深度のぼかし・光の玉ボケ・周辺減光・フィルム粒子で写真らしく見せている
- 実在の写真ではないことを明記する: 画面に「※ 写真はCGによるイメージです」、SVG の title にも「CG によるイメージ」。架空の風景で、特定の実在施設を写したものではない
- ベクター形式なので 1 枚 7〜19KB と軽く、どの画面サイズでもぼやけない。シード固定で再生成しても同じ絵になる

### 切り替え方
- 管理画面「共通 > サイト設定」で UI テーマを選んで保存すると、**ログイン前を含む全員**に反映(監査ログに記録)
- 管理者は URL に `?ui=game` などを付けると**自分のセッションだけ**で試し見できる(画面上部に青い帯が出る。`?ui=reset` で解除)。一般利用者は `?ui=` を付けても変わらない
- 設定は 60 秒キャッシュ。管理画面から保存したときはすぐ反映される
- 新しい案は `THEMES` に 1 行足し、`static/css/themes/<名前>.css` と必要ならテンプレート `core/landing_<名前>.html` / `core/home_<名前>.html` を用意するだけで追加できる(テンプレートがなければスタンダードを使う)

## トレードオフ

- B〜D はライト表示固定(ダークモードの配色は未対応)
- B の 1 画面ホームは縦 560px 以上を前提にしている(それ未満では一部が詰まる)。横長の PC 画面では中央にスマホ幅で表示する
- 明朝体は OS のフォントに依存(Web フォントは読み込まない = 外部通信なし・CSP を緩めない)
