再訪率・アプリ利用率

再訪率 = 期間の中で 2 日以上来た人 ÷ 1 日以上来た人 × 100。「来た日」はみっけした日かクーポンを使った日(同じ日に何回でも 1 日)。ログインしただけの日は数えません。 アプリ利用率 = その日にアプリを使った利用者 ÷ その日までに登録していた利用者(ログインしただけの日も数えます)。管理者・サイト運営者・停止中の人は数えません。

  • アプリ利用率(今日){% if data.usage_today.rate is not None %}{{ data.usage_today.rate }}%{% else %}—{% endif %} {{ data.usage_today.active|num }} / {{ data.usage_today.registered|num }} 人
  • アプリ利用率(30 日の平均){% if data.usage_avg is not None %}{{ data.usage_avg }}%{% else %}—{% endif %} 日ごとの利用率の平均
